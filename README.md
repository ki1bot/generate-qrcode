# Project QR Code Generator

Project QR Code Generator adalah aplikasi web untuk membuat QR Code secara cepat, rapi, responsif, dan siap diunduh sebagai file PNG.

Aplikasi ini dibuat menggunakan React, JavaScript, TypeScript, Vite, Tailwind CSS, dan qrcode.react.

## Preview Fitur

- Membuat QR Code secara otomatis dari input user
- Mendukung input URL website
- Mendukung email dan mengarah ke Gmail Compose
- Mendukung nomor telepon Indonesia dan mengarah ke WhatsApp
- Mendukung format WhatsApp dengan pesan otomatis
- Mendukung format telepon
- Mendukung format SMS
- Mendukung teks biasa dan mengarah ke halaman browser yang menampilkan teks tersebut
- Bisa mengubah warna QR Code
- Bisa mengubah warna background QR Code
- Bisa download QR Code sebagai PNG
- Bisa copy target output QR Code
- Tema terang dan tema gelap
- Responsive untuk desktop dan mobile

## Teknologi yang Digunakan

- React
- TypeScript
- Vite
- Tailwind CSS
- qrcode.react
